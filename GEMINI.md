# Gemini CLI Instructions

This repository keeps a single, canonical set of agent instructions in
[`AGENTS.md`](AGENTS.md). This file exists only so that the Gemini CLI loads
them automatically; it deliberately holds no rules of its own, so that the two
can never drift apart.

@AGENTS.md

If your runtime does not support the `@` import above, read
[`AGENTS.md`](AGENTS.md) directly before making any change.
